# Single-Page CV

An Frontend Project:
https://roadmap.sh/projects/single-page-cv

A semantic, single-page Curriculum Vitae built with HTML only. No CSS, JavaScript, frameworks, or external libraries are required.

## Project files

- `index.html` — the CV page and its SEO/Open Graph metadata.
- `favicon.svg` — the page favicon.

## Run locally

1. Download or clone this repository.
2. Open `index.html` directly in a web browser.

No build tools or local server are required.
